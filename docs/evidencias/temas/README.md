# Evidência: 22 Temas (#203)

Capturas da interface em Escuro (`dark`), Feltro, Torneio e Pretas, com o Ribbon, o dock e a barra de status.
Geradas com `chess-studio --screenshot <dir> --panel --theme <id> --moves e2e4,e7e5 --select g1 --size 1280x720`
(o `--theme` aceita qualquer id de `docs/design/themes.json`).

O tabuleiro não muda com o Tema: as casas e as peças são as mesmas nas quatro capturas.
