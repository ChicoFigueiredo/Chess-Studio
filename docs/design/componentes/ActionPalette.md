# ActionPalette

A Paleta de Ações (Ctrl+K) busca qualquer Ação pelo nome e a executa com Enter.

- Lista com ícone, rótulo e atalho. Ações desabilitadas aparecem com o motivo, sem executar.
- Véu `scrim` atrás, diálogo com `radius-xl` e `shadow-dialog`.
- **egui:** `egui::Modal` com `TextEdit` focado e uma lista filtrada da mesma lista de Ações.
